Las palabras de un pueblo misterioso

Vocabulario para leer «Algo muy grave va a suceder en este pueblo».

1. Relaciona las palabras y las definiciones

Observa las dos columnas. Todas las definiciones están visibles. Selecciona una letra para cada palabra. No puedes usar dos veces la misma letra.

2. Descubre palabras con imágenes

Observa las imágenes, lee las explicaciones y busca las palabras en el texto. No necesitas memorizarlas.

3. Usa las palabras en otras situaciones

Completa cada frase con una palabra del recuadro. Todas se utilizan una vez.
